## ۲. قوانین طلایی هوش مصنوعی در این پروژه (System Guardrails)
1. **ممنوعیت حدس زدن اعداد:** هیچ عدد، مبلغ یا درصدی نباید بدون استناد به ردیف جدول یا شماره نامه مرجع گزارش شود.
2. **جداسازی فکت از تخمین:** هرگونه عدد شفاهی یا تاییدنشده باید با برچسب `[نیازمند راستی‌آزمایی ⚠️]` مشخص گردد.
3. **قالب خروجی استاندارد:** تمام گزارش‌های مدیریتی باید شامل خلاصه ۳ خطی، جدول شاخص‌ها و لیست گلوگاه‌های اقدام فوری باشند.
